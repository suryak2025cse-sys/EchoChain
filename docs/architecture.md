# EchoChain System Architecture & Specification

## High-Level Overview
EchoChain is a privacy-preserving provenance platform using environmental acoustic signatures, cryptographic hashing, IPFS decentralized storage, and Polygon smart contracts.

## Technical Core Rules
1. **Privacy Protection**: Exact GPS coordinates are protected. Only region-level location boundaries are exposed.
2. **SHA-256 Immutability**: SHA-256 provides tamper-evident data integrity. Location match evidence is generated via probabilistic acoustic embedding comparison.
3. **Decentralized Storage**: Audio payloads are uploaded to IPFS. Hashes and CIDs are anchored on Polygon blockchain.
